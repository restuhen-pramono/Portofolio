# Restu Hendra Pramono

Modern mechatronics & industrial automation portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- Responsive Design
- Dark/Light Mode
- Smooth Animation
- Interactive UI
- Project Showcase
- Contact Integration

## Technologies

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Installation

```bash
npm install
npm run dev
